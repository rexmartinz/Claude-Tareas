# Lector de Archivo de Pagos

Herramienta de una sola página (`index.html`, sin build ni backend) para leer y
validar archivos de pagos de ancho fijo/delimitados de distintos formatos
bancarios: 0291, 0DG0, PR5, Débito por CBU, GIRE Nuevo (Rapipago), GIRE Viejo
BDP y ALV — además de un modo de ingreso manual interactivo.

Todo el procesamiento ocurre en el navegador. Las tablas de referencia
(Contratos y Cuentas, Impuestos, Contratos por empresa) pueden actualizarse
cargando un Excel, y quedan guardadas localmente en el navegador.

## Uso

Abrí `index.html` en el navegador — no requiere instalación ni servidor.
