Tabla de Contratos y Cuentas
Usando la tabla por defecto (30 entes).
El Excel debe tener columnas con encabezados "Ente", "Contrato", "Cuenta" y "Descripción del ente". Se actualiza por código de Ente (no hace falta traer todos los entes ni respetar un orden) — si el código no existe todavía, se agrega como uno nuevo. Esta tabla se usa para todos los tipos de archivo que identifican registros por Ente/Cuenta (por ahora, PR5 y ALV).
Revisá la vista previa y confirmá para aplicar y minimizar esta tabla.
Tabla de Impuestos (Contrato / Cuenta / Subcuenta)
Usando la tabla por defecto (30 códigos de impuesto).
El Excel debe tener columnas con encabezados "Contrato", "Impuesto", "Cuenta" y "Subcuenta". Se actualiza por código de Impuesto (no hace falta traer todos los códigos ni respetar un orden — el Nombre del impuesto siempre viene de la tabla ya cargada). Códigos agrupados (00/09, 03/31, 04/05, 10/11, 14/27, 15/17, 19/26, 22/28): si traés solo uno del par, el otro se actualiza igual automáticamente. Se usa en todos los archivos que muestran impuesto: 0291, 0DG0, Débito por CBU y GIRE Nuevo (.6105).
Revisá la vista previa y confirmá para aplicar y minimizar esta tabla.
Tabla de Contratos (Contrato / Cuenta / Subcuenta / Nombre Empresa)
Todavía no se cargó ninguna. Es la tabla principal para el Ingreso Interactivo.
El Excel debe tener columnas con encabezados "Contrato", "Cuenta", "Subcuenta" y "Nombre Empresa". Se actualiza por número de Cuenta (no hace falta traer todas ni respetar un orden — si la cuenta no existe todavía, se agrega como nueva). Esta es la tabla principal de entidades para el Ingreso Interactivo, y también de donde se levantan Iosep, Municipalidad de Santiago y Municipalidad de La Banda (buscando por Nombre Empresa).
Revisá la vista previa y confirmá para aplicar y minimizar esta tabla.
